# c-logic-programs
C Sequential Logic Programs   A beginner‑friendly collection of classic C programs demonstrating fundamental logic building. This repo combines multiple logic tasks into a single file (non‑menu driven, sequential execution) so learners can see how different concepts flow together.

Programs Included
✅ Even or Odd check

✅ Reverse digits of a number

✅ Prime number test

✅ Sum of digits

✅ Factorial calculation

🎯 Why This Repo?
Clear, easy‑to‑understand code for beginners.

Covers essential control structures (if, for, while).

Sequential execution shows how different logic problems can be solved in one flow.

Perfect for students practicing problem‑solving in C.



🚀 How to Run
bash
gcc logic.c -o logic
./logic


Enter a number when prompted, and the program will display:

1:Whether it’s even or odd

2:Its reverse

3:Prime check result

4:Sum of digits

5:Factorial
